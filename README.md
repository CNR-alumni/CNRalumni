# CNR Alumni

เว็บไซต์สมาคมศิษย์เก่าโรงเรียนชิโนรสวิทยาลัย

Static HTML/CSS/JavaScript. No dependencies or build step.

- Main source: `index.html`
- Images: `assets/`
- Preview: `python3 -m http.server 8000`
- GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
- Expected site URL: https://cnr-alumni.github.io/CNRalumni/

Imported from the existing CNR Alumni website. News and some content are demonstration content.
